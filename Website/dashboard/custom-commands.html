How custom commands work

Use this section to keep shortcuts predictable and safe.

Prefix rules
Custom commands only use the default prefix set in Server Settings, for example .rules. Other built-in prefix aliases do not trigger these custom commands.
Private responses
A direct-message response is private to the person who ran the command. If their DMs are closed, Auralis can only show a brief delivery notice in the channel.
Mentions and permissions
Custom responses disable mass mentions by default. Bot permissions and Discord's role hierarchy still apply to all server actions.
Server-specific settings
Saved shortcuts belong to this server and do not change commands or replies in other communities.
