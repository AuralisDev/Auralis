Advanced channel rules

Set an override for an individual channel using its Discord channel ID. These overrides are merged over the server-wide AutoMod options.

Use a valid JSON object keyed by channel ID. Each override can set rule options such as antiLink, messageRate, exemptRoleIds or exemptUserIds. Keep a backup before editing.

Keyword responses

Reply automatically when a message contains a phrase. Channel, role, match type, cooldown, private reply and embed options are supported.

Placeholders: {user}, {username}, {server}, {channel}, {prefix}, {memberCount}, {userId}, {guildId}. Match types: contains, startsWith, exact; response modes: channel, reply, dm. An optional embed can define title, description, colour, image, thumbnail, URL, footer and timestamp.

AutoMod message templates

Personalise the notice members receive. Placeholders include {server}, {rule}, {channel}, {reason}, {action} and {caseId}.
