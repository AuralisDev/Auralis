Only used for ticket panels. Configure ticket panels in Dashboard → Ticket Panels.
Select a panel and channel, then send it. Auralis will return a link to the posted Discord message.

What each panel does

Ticket panelCreates ticket channels from the configured ticket panel.
Application panelShows buttons for the application forms configured for this server.
Verification panelGives the configured verified role when clicked, provided Auralis has Manage Roles and is above that role.
Staff activityAllows staff members to record a check-in using the existing staff-activity interaction.
Setup menuPosts the interactive quick-setup menu with module sections.
The bot needs View Channel and Send Messages in the selected channel. Ticket, role, application, and verification features also require their corresponding role/channel settings.
