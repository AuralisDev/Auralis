Placeholders and previews

Common placeholders include {user}, {username}, {server}, {moderator}, {reason}, {caseId}, {warningId}, {duration}, {expiresAt} and {channel}. A specific message may support only a subset of these values. Unknown placeholders are left as typed.

Discord cannot deliver DMs when a member blocks direct messages from server members. Auralis reports the delivery result where a command or system supports it; changing a template cannot override Discord privacy settings.
