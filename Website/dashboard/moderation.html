Audit notes & response workflow

Moderation commands acknowledge work ephemerally so busy API actions do not exceed Discord's interaction response deadline. Auralis sends the member's DM once after the moderation action succeeds; if the DM cannot be delivered, the moderator receives that status in the command response. Temporary bans include the exact expiry time and relative countdown when recorded. Use /warnings, /history, /caselog, /unwarn, /pardon, /banlist, /unban, /mute, /tempmute and /unmute for the matching workflow.

A server owner and Administrator can manage staff actions without the acting staff member being higher in the role hierarchy. Discord still requires Auralis itself to have the required permission and a role above the target or target role.
