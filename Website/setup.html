AURALIS · DASHBOARD

Fast fertig. Das Backend fehlt noch.

Die öffentliche Website läuft auf GitHub Pages. Der sichere Discord-Login und das Speichern der Einstellungen benötigen zusätzlich einen laufenden Auralis-Backend-Host. GitHub Pages kann Node.js nicht ausführen.

  1. Stelle den Ordner DiscordBot auf einem Node.js-Host bereit und starte Bot und Dashboard-API gemeinsam mit npm run start:all.
  2. Lege dort DISCORD_TOKEN, DISCORD_CLIENT_ID, DISCORD_CLIENT_SECRET, die passende DISCORD_REDIRECT_URI und einen zufälligen SESSION_SECRET als private Umgebungsvariablen an.
  3. Trage die öffentliche HTTPS-Backend-URL in Website/config.js bei apiBase ein und veröffentliche die GitHub Pages Website erneut.
  4. Registriere exakt https://DEIN-BACKEND/auth/discord/callback unter Discord Developer Portal → OAuth2 → Redirects. Das Backend fordert für den Login identify und guilds an.

Nach der Einrichtung führt „Login with Discord“ zur sicheren Autorisierung. Danach werden Server angezeigt, auf denen dein Account Owner ist oder Administrator-/Manage-Server-Rechte hat. Die Einstellungen werden getrennt nach Discord-Server gespeichert.
