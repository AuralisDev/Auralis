Local Dashboard

Run npm run dashboard. Auralis starts the website and dashboard locally and opens the browser automatically when the environment allows it. Local dashboard requests use the same origin, so you do not need a public domain or CORS configuration.

GitHub Pages

The Website folder is the static frontend inside the AuralisDiscordBot repository. GitHub Pages supports free project sites on the default github.io domain, so no custom domain is required.

Upload the project folder contents to the repository root and enable Pages with the root-level GitHub Actions workflow. The static site can show the homepage, command catalogue, help pages and status page without a custom domain.

Discord OAuth

For local development, Auralis uses http://localhost:3000/auth/discord/callback. Add that exact URL under Discord Developer Portal → OAuth2 → Redirects. Discord compares the registered redirect URI with the authorization request, so even a different host, path or trailing slash will be rejected. For a GitHub Pages deployment, keep the public homepage on Pages but register the separate backend callback URL. After login, redirect to the dashboard on the backend host (same origin), not to the GitHub Pages copy of the dashboard, so the session cookie works more reliably.

Public Servers

Server owners can enable or disable their public listing in the dashboard. The public API returns the server name, description, member count, icon and optional invite link.

Security

Never commit .env, bot tokens, client secrets or session secrets. The dashboard enforces Administrator permission checks on every protected guild request, not only during login.

For an optional public backend without a custom domain, Render provides free Web Services with an onrender.com address. Free instances can spin down after 15 minutes of no inbound traffic and have an ephemeral filesystem, so this is best treated as a hobby/test deployment rather than durable production storage.
