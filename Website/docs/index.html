How can we help?

Quick answers for server owners and staff using Auralis.

Add AuralisConfigure a serverCommandsPermissionsPrivacyGet help

Add Auralis to your server

Choose Add to Discord, select the server you manage and review the permissions requested by the bot. Auralis needs its relevant permissions and access to the channels where you want to use its features.

Configure your server

Choose Login with Discord on the Auralis homepage. After signing in, select a server where you are the owner or have the required server-management permissions. Each server has its own settings, panels and message templates.

Find a command

Open the command catalogue to search commands by name or category. Slash commands show their required and optional options. For prefix commands, use the prefix configured for your server.

Why is a feature unavailable?

Check the bot's role position and channel permissions. Some features also need a Discord Gateway Intent to be enabled by the application owner. A user must have the required server permission to manage that part of the server.

Privacy and public listing

Server owners control whether their community appears in the public server directory. Disable the listing in server settings at any time. Private dashboard settings are separate for each Discord server.

Need more help?

Visit the community support link provided by Auralis, or ask a server administrator to review the bot's permissions and settings.
