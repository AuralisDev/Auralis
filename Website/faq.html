Quick answers

Questions? Answered.

Helpful answers for server owners, moderators and community members.

How do I add Auralis to my server?

Choose Add bot, select the server you manage and review the requested permissions. Auralis can only use the permissions Discord and your server allow.

How do I configure my server?

Choose Login with Discord on the homepage, then select a server where you are the owner or have permission to manage it. Each community keeps its own settings, panels and response templates.

Why can't I see one of my servers?

The server appears in your list when your Discord account has the required management permission. Check that you are signed into the right Discord account and that your role can manage the server.

Can I change settings for one server without affecting another?

Yes. Auralis keeps configuration separate for each Discord server. Changes to welcome messages, moderation, tickets, applications or public listing apply only to the selected community.

How do I find a command?

Open the command catalogue, search by name or purpose, or filter by category. Required options are shown in angle brackets such as <user>; optional options appear in square brackets such as [reason].

Why can't Auralis moderate a member?

Discord does not allow a bot to moderate the server owner or members whose highest role is equal to or above the bot's highest role. Check the bot's role position and the relevant channel or server permissions.

Why didn't a member receive a moderation DM?

Members can disable direct messages from server members or block them entirely. The moderation action can still succeed even if Discord does not allow the private message to be delivered; staff should check the command's result.

Can I create more than one ticket panel or application?

Yes. Create separate panels and forms for different support teams, topics or staff workflows. Give each one a clear name and send it to the channel where your members should use it.

Can I hide my server from the public directory?

Yes. Server owners and authorized staff can disable public listing in the server's privacy settings. Private server settings remain separate from the public directory.

How can I configure logs?

Choose the events you want to record and assign a channel for each log category. Remember that Discord may require additional permissions or gateway intents for some kinds of events.

Where can I get help?

Start with the Auralis Help Center and the command catalogue. If a feature is unavailable, ask a server administrator to check the bot's permissions and role position.
