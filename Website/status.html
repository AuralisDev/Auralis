How to read this page

Online means a fresh heartbeat has been received within the last 45 seconds. Reconnecting means the gateway is restoring its connection. If the process crashes or stops sending heartbeats, the status changes to Offline even if its token is still configured. Server and member figures are persisted last-known index counts; member counts depend on the bot's available Discord cache and intents.

The status endpoint checks the bot process, not all Discord services. A failure to load the status API is shown separately from the bot's own status.
